## 📌 Sobre o Projeto
O **Gasto na Foto** é uma aplicação web voltada para controle financeiro prático. O usuário envia ou fotografa um comprovante fiscal, e a Inteligência Artificial faz a leitura da imagem, extrai os valores e calcula o total acumulado automaticamente.

## 🚀 Tecnologias e Ferramentas
* **HTML5:** Estruturação semântica da aplicação.
* **CSS3:** Estilização visual, layout e responsividade.
* **JavaScript:** Lógica de navegação e manipulação dinâmica dos dados.
* **Puter.js:** Integração com Inteligência Artificial para leitura (OCR) dos comprovantes.
